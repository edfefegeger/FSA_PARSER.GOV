ПАРСЕР РЕЕСТРА ФСА - ИНСТРУКЦИЯ
================================

УСТАНОВКА В LINUX (Ubuntu/Debian)
    sudo apt install python3-venv     # если ещё нет
    chmod +x run.sh
    ./run.sh                          # сам создаст .venv и поставит зависимости
Команда pip install без venv в Ubuntu 24.04 не работает (защита PEP 668) - это нормально.
Вручную:  python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
          .venv/bin/python fsa_parser.py

УСТАНОВКА В WINDOWS (один раз)
1. Установите Python 3.9+ с python.org (при установке отметьте "Add Python to PATH").
2. Откройте командную строку в папке с парсером и выполните:
       pip install -r requirements.txt

ЗАПУСК (каждую неделю)
- Linux:   ./run.sh   (аргументы те же: ./run.sh --days 90)
- Windows: двойной клик по run.bat
  или в консоли:  python fsa_parser.py
- Разово изменить порог:  python fsa_parser.py --days 90

РЕЗУЛЬТАТ
Файл появляется в папке "выгрузки": fsa_60_days_ГГГГ-ММ-ДД.xlsx
Старые выгрузки не перезаписываются (при повторном запуске в тот же день
добавляется _2, _3 ...). Документы, истекающие в течение 30 дней, выделены красным.

НАСТРОЙКИ (config.ini, открывается Блокнотом)
- days_threshold    - за сколько дней до окончания включать документ
- product_keywords  - слова/корни слов для фильтра по продукции
- document_types    - сертификаты, декларации или оба
- format            - xlsx / csv / both
- columns           - состав и порядок столбцов
- urgent_days       - порог красной подсветки
Частота запуска - это просто то, как часто вы запускаете run.bat.

ЕСЛИ САЙТ ОБОРВАЛ СОЕДИНЕНИЕ / ЗАБЛОКИРОВАЛ IP
Парсер сам останавливается при первых признаках блокировки (не долбит сайт повторами),
сохраняет всё найденное в папку cache и пишет файл ..._частично.xlsx.
Подождите (при блокировке - несколько часов) и запустите ещё раз: продолжит с места
остановки. Чтобы не вызывать блокировку:
- паузы между запросами (delay, batch_pause) не уменьшайте;
- поставьте max_requests = 300: парсер сам остановится после 300 запросов, запускайте
  его несколько раз в течение дня - каждый запуск продолжает предыдущий;
- повторные недельные запуски берут данные заявителей из кэша (30 дней) и почти
  не нагружают сайт.
Папку cache можно удалить - тогда всё загрузится заново.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
- Пустые "ФИО руководителя" или "e-mail": запустите  python fsa_parser.py --debug
  и пришлите разработчику файлы debug_*.json - это ответы сайта, по ним
  поле подправляется за минуты.
- Ошибки сети: парсер сам повторяет запросы; при повторяющихся сбоях увеличьте
  delay в config.ini.
- Сайт ФСА может изменить свой API - в этом случае понадобится обновление парсера.
